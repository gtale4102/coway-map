## 데이터 구조 (구글시트 A1에 JSON으로 통째 저장)
```
{ customers: [...], categories: [...], routeHistory: [...], trash: [...] }
```
- **customer**: `{ id, name, category(분류ID), memo, contacts[{name,phone}], addresses[{label,address,detail,lat,lng}], lat, lng(대표좌표=첫주소), owner('태일'|'정열'), logs[{type,date,memo}], createdAt }`
- **category**: `{ id, name, color }` — 기본 5개 + 고정 항목 "미분류"(id: `cuc`, 이름변경/삭제 불가)
- **routeHistory**: `{ id, stops[], origin, label, savedAt }` — 최대 10개 유지
- **trash**: 삭제된 customer 전체 + deletedAt — 최대 200개 유지

## ⚠️ 저장 방식 — 매우 중요, 반드시 숙지
- **doPost**: form(POST) + 숨김 iframe 방식으로 전송 (URL 길이 제한 회피, 대용량 데이터 저장 가능)
- **doGet**: JSONP 방식 (callback 파라미터)
- **저장 시 병합(mergeAndSaveToSheet)**: 저장 직전 원격 데이터를 가져와서 로컬에 없는 항목을 병합 → 두 사람이 동시에 다른 고객사를 추가해도 서로 안 덮어씀

### 과거 발생했던 치명적 버그와 해결책 (재발 방지 필수)
삭제 시 위 병합 로직이 "로컬에 없으니 누가 방금 추가했나보다"라고 착각해서 **삭제한 항목을 되살리는 버그**가 있었음 (고객사 삭제, 경로기록 삭제 둘 다에서 발생했었음). 정열님이 입력한 고객사 20~30개가 이 버그로 영구 소실된 사고가 있었음.

**해결 — tombstone(삭제기록) 패턴:**
- `localStorage['coway_deleted_ids_v1']` — 삭제된 customer id 배열 (최근 500개)
- `localStorage['coway_deleted_route_hist_v1']` — 삭제된 routeHistory id 배열 (최근 100개)
- `markDeleted(id)`, `markManyDeleted(ids)`, `markRouteHistDeleted(id)` 함수로 **삭제 직전 동기적으로** 기록
- 병합 단계에서 이 tombstone 목록에 있는 id는 절대 다시 추가하지 않음

**🔴 원칙: 앞으로 삭제 관련 기능을 만들거나 수정할 때는 반드시 삭제 전에 markDeleted류 함수를 동기적으로 먼저 호출할 것.** 이게 빠지면 같은 데이터 유실 버그가 재발함.

### 저장 검증(verification) 관련 — 다시 추가하지 말 것
한때 저장 후 재확인(검증) 로직을 추가했었으나, 구글 API의 일시적 403 오류 때문에 정상 저장된 것도 "저장 실패"로 잘못 경고하는 부작용이 있어서 **제거함**. 현재는 "저장 요청 보내고 바로 진행, 검증 없음" 방식. 데이터 안정성은 (1) POST 방식(용량 제한 없음) + (2) 병합+tombstone으로 확보되어 있음. **검증 로직을 다시 넣자고 제안하지 말 것.**

## 사용자 시스템
- 최초 접속 시 "김태일" / "정열" 선택 화면 (`localStorage['coway_user_v2']`, 한 번 선택하면 이후 자동 로그인)
- 설정에서 "사용자 변경"으로 재선택 가능
- 상단 필터: 전체 / 나 / 상대방 (currentUser 기준 동적 라벨)
- 고객사 추가 시 owner는 자동으로 현재 로그인한 사용자로 설정 (수동 선택 없음)
- 분류(categories)는 두 사람이 공유
- 컨택 리마인드는 본인 소유 고객사만 체크 (`owner === currentUser`)
- PIN 잠금 6자리, 기기별 개별 설정

## 주요 기능 목록
1. 카카오맵 기반 지도, 고객사 핀 (분류별 색상, 복수 주소면 각각 핀 표시)
2. 핀 클릭 → 상세정보 (담당자/주소+상세주소/컨택통계/이력/메모, 로드뷰, 길찾기)
3. 고객사 추가/수정/삭제 (주소는 다음 우편번호 검색)
4. 컨택 기록 (방문/전화/문자, 날짜 지정 가능)
5. 전체 컨택 이력 (날짜순/고객사순, PDF 내보내기 — HTML 다운로드 후 인쇄로 PDF 변환)
6. 컨택 리마인드 (일수 설정, 지도 배너, 핀에 노란 느낌표 배지)
7. **동선짜기**: 출발지(현위치/고객사주소/직접입력, PC는 현위치 비활성화), 경유지 추가(고객사 전체필드 검색 또는 직접 주소입력), 카카오모빌리티 API 실선 경로+구간별 시간, 목적지 1곳만으로도 가능, 최근 경로 히스토리(최대10개, 좌우스크롤), 패널이 화면 거의 끝까지 확장됨
8. 전체 고객사 목록: 소유자 필터 연동, 주소구분 표시, **길게 눌러 다중선택삭제**, 목록→상세→삭제 시 목록으로 복귀
9. 검색(상단): 이름/주소/담당자/메모/소유자/분류 전체 검색, 🔍 버튼으로 검색어 매칭 고객사만 지도 필터링
10. 분류 관리: 색상/이름 변경, 순서 ▲▼ 버튼(드래그 아님, 아래 "보류 항목" 참고), "미분류" 고정항목
11. 휴지통: 삭제된 고객사 복원 가능
12. 엑셀 일괄 가져오기: 같은 고객사명 행 자동 그룹화, 자동 지오코딩, 분류 매칭 실패 시 "미분류"
13. 데이터 내보내기/가져오기 (JSON)
14. 상호 표시 토글 (핀 아래 이름표 on/off)
15. PWA 메타태그 + 아이콘 (icon-192.png, icon-512.png — 코웨이 B2BC 로고+지도 디자인, GitHub에 업로드됨)
16. 인앱브라우저(네이버앱 등) 감지 배너 — 파일첨부/팝업 제한 안내
